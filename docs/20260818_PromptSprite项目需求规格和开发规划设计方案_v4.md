## 二、项目整体定位

**PromptSprite** 是一款专为 AI 创作者打造的"提示词私人管家"：把杂乱无章的 Prompt 文档变成**四级分类书架 + 极速检索 + 一键复制**的本地神器。双击 `.exe` 即可使用，数据全部保存在本机，**无任何联网行为**。

**交付标准（已达成）**：独立 `PromptSprite.exe`（约 21MB）；Windows 10/11；本地 SQLite 存储；3800+ 条检索秒级响应；单文件绿色运行，无需安装。

## 四、数据模型（v2）

### 4.1 核心设计

- 分类为**全局共享树**（`categories` 无领域归属列），`domain_category` 关联表实现"多领域共享同一级分类"（多对一）；
- 外键安全：删除分类级联子分类、其下条目 `SET NULL` 自动转入"未分类"；删除领域仅解除关联（共享数据保留）；
- 预置根目录 8 个：计算机编程、视频、图像、音频、文学、学术、专业报告、视觉风格分类。

### 4.2 当前数据规模（2026-08-18）

| 根目录 | 条目数 | 说明 |
| ---- | ---- | ---- |
| 计算机编程 | 20 | 提示词工程/开发 |
| 视频 | 0 | 空根目录（共享视觉风格分类） |
| 图像 | 1151 | 517 基础 + 提示词拆解案例 7 + SDXL摄影风格 145 + 时尚搭配 450 + 手绘插画 32 |
| 音频 / 文学 / 学术 / 专业报告 | 0 | 空根目录 |
| 视觉风格分类 | 90 | 内置手册 |
| 海外AI绘画案例库 | 1791 | moosl 全量（第014条） |
| AI绘画精选案例 | 494 | davidwuw0811（第014条） |

### 4.3 条目字段

①名称 ②介绍 ③溯源 ④核心特征 ⑤应用场景 ⑥代表作 ⑦代表高清配图 ⑧中文版提示词 ⑨英文版提示词 ⑩图像获取方案 + 关联图片/收藏/时间戳。

### 4.4 内置手册升级机制

`BUILTIN_MANUAL_VERSION` 变更时执行**非破坏性合并**（分类按名复用、条目按名 upsert，保留用户收藏与图片），**不清理任何现有数据**。

## 五、交互规格（V4 现状）

### 5.1 详情字段按根目录动态显隐

| 当前查看的根目录 | 详情区字段 |
| ---- | ---- |
| 视觉风格分类 / 视频 / 图像 | 9 字段全部显示 |
| 计算机编程 / 音频 / 文学 / 学术 / 专业报告 / 其他新建根目录 | 默认隐藏 ③-⑦，突出提示词 |

- 设置入口提供三档策略：**自动**（按根目录）/ **全部显示** / **精简**；
- 精简模式下详情区标题显示"详情 · 精简模式"，并提供"⏵ 显示全部字段"临时展开按钮（会话级）；
- 隐藏字段保存时保留数据库原值（`_detail_hidden` + `_field()`），防止误清空。

### 5.2 提示词文本框高度（像素单位）

- 有内容：默认 120px（6 行可见）；"展开"后高度自适应内容实际显示行数（含自动换行）；"收起"恢复；
- 无内容：1 行空行（24px），无展开按钮。

### 5.3 状态栏动态统计（悬停联动）

- 无选择：`总提示词数 X｜一级目录 Y｜二级目录 Z｜条目数 X`；
- 悬停根目录：追加 `根目录【名称】提示词 N`；
- 悬停一级/二级：追加 `一级【】提示词 M` / `二级【】提示词 K`；
- 悬停条目：追加 `条目【名称】`。

### 5.4 数据导入去重（P1-1）

- Excel/JSON 导入按 **"详情内容"（名称+②~⑩ 九个字段拼接）** 判重，完全相同才跳过；名称相同但内容不同仍新增；
- 导入结果提示"新增 X 条，跳过重复 Y 条"。

## 六、技术实现（V4 更新）

| 部件 | 选型 | 说明 |
| ---- | ---- | ---- |
| UI | CustomTkinter 5.2+（内置 tkinter） | 亮色主题，三列+条目+详情布局 |
| 数据库 | SQLite 3（标准库 sqlite3） | 免安装、单文件；外键约束开启 |
| 剪贴板/热键/托盘 | pyperclip / keyboard / pystray | 热键失败降级提示 |
| Excel/图片 | openpyxl / Pillow | 导入导出、预览、图标 |
| 打包 | PyInstaller（onefile + windowed） | 单 EXE，资源内嵌 |
| 安装/迁移 | JSON 完整备份导入导出 | 跨机迁移 |

**模块结构**：`app/main.py`（启动编排）、`config.py`（常量）、`database.py`（数据层 v2）、`models.py`（Entry）、`backup.py`（备份）、`hotkey.py`（热键/托盘）、`self_test.py`（统一自测）、`parser/`（md/json/excel/html）、`ui/`（main_window/quick_add/move_selector/progress_dialog/settings_dialog）、`resources/builtin_manual.md`。

**关键实现要点（V4）**：
- 批量插入 `Database.add_entries_batch`（单事务，大文件导入性能）；
- 内容判重 `Database.content_key`（静态方法，兼容 dict/Entry）；
- 图片路径越界校验（`data/` 内，含异盘防护 P2-1）；
- 状态栏统计递归计数 `_cat_entry_count` / `_domain_entry_count`；
- 非破坏性合并导入 `import_manual` + `_upsert_entry`。
