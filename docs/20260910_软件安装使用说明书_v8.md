## 1. PromptSprite 是什么？能做什么？

**一句话版**：PromptSprite（提示精灵）是一个装在你自己电脑上的"AI 提示词图书馆"，帮你把几千条到处乱放的提示词整整齐齐地分类放好，想用的时候一搜一点就能复制走。

**再直白一点**：如果你平时用 AI 画画、写东西，会攒下很多"好用的指令文本"（比如某个画风的中文/英文提示词）。以前它们可能散落在记事本、Excel、聊天记录里，找起来很痛苦。PromptSprite 就是专门管这些东西的小工具——**所有数据都存在你自己的电脑里，不联网、不上传**。

它能做的事，用大白话列出来：

| 序号 | 它能做什么 | 对你有啥用 |
|---|---|---|
| 1 | 像书架一样分层收纳提示词 | 项目类别 → 根目录 → 一级分类 → 二级分类 → 条目，再多也不乱 |
| 2 | 极速搜索 | 输入几个字，立刻从全部文字里找出相关条目 |
| 3 | 一键复制 | 复制"全部 / 只复制中文 / 只复制英文"，拷到 AI 对话框直接用 |
| 4 | 快速新建 | 鼠标"滑过去"就能锁定分类，连续录入几十条不打断 |
| 5 | 自动全量备份 | 每次打开软件自动把整个数据库存一份，出问题能退回 |
| 6 | 每日变更包 | 每天关软件时把当天的"新增/删除"自动打包，可拷到另一台电脑合并 |
| 7 | 回收站/删除历史 | 删错了？去回收站一键恢复，内容、收藏、位置都还在 |
| 8 | 多格式导入导出 | JSON / Excel / Markdown / HTML，从别处整理的数据能倒进来 |
| 9 | 老数据迁移 | 老版本的数据升级后自动迁移，不丢 |
| 10 | 数据比对 | 拿今天的数据和某一天的备份对比，看看到底多了啥、少了啥（只读，安全） |

**软件自带内容（内置精简模板）**：4 个项目类别、10 个根目录、约 2555 条提示词示例（主要集中在"网上资源收集"下），打开就能看、能抄、能改。

### 2.2 去哪里拿软件

- 开源仓库发布页：<https://github.com/yihufree/PromptSprite>（软件还在持续完善，正式打包文件会在仓库 Releases 里发布；仓库里也有全部源码，仅供学习与个人使用）。

## 3. 两种运行方式：打包 EXE 与从源码运行

### 方式一：使用打包好的 EXE（推荐给所有普通用户）

打包好的程序是一个单文件，命名规则是：

```
PromptSprite_<打包日期YYMMDD>_V<版本号>.EXE
```

例如：`PromptSprite_260907_V1.6.0.EXE`；V1.8.0 的包会是类似 `PromptSprite_260910_V1.8.0.EXE` 的名字。

安装步骤（其实不用"安装"，解压即用）：

1. 把下载到的 EXE 文件放到一个**英文路径**的文件夹里，例如 `D:\PromptSprite\`（路径里有中文有时会被杀毒软件或系统误伤）。
2. 双击这个 EXE 启动。第一次启动需要几秒到几十秒（要自动准备数据），**期间不要关窗口**。
3. 程序会在 EXE 所在的文件夹里自动创建一个 `data` 文件夹（你的全部数据都在里面，见第 3.3 节）。

> 换电脑/换文件夹：**请把整个文件夹（包括 `data` 文件夹）一起复制**，而不是只复制 EXE。只拷 EXE 不拷 `data`，新电脑上是空白模板数据。

### 方式二：从源码运行（开发者 / 爱折腾的用户）

软件是 Python 写的。想从源码跑，需要自己准备环境：

1. 安装 Python（3.10 及以上，推荐 3.12）。
2. 把仓库源码下载/克隆到本地。
3. 在项目根目录打开命令行（PowerShell），安装依赖：
   ```
   pip install -r requirements.txt
   ```
4. 启动软件（二选一，效果一样）：
   ```
   python -m app.main
   ```
   或
   ```
   python run.py
   ```
5. 程序启动后，数据文件夹在**项目根目录**下的 `data\`（和 `app\` 平级）。

> 小提示：源码方式运行时，如果缺了第三方库，软件会尝试自动 `pip install` 补齐；自动安装失败时按提示手动执行上面第 3 步即可。

### 3.3 `data` 数据文件夹里到底有什么？（重要，先看懂再动手）

不管哪种运行方式，你的全部家当都在 `data` 文件夹里。它的结构长这样：

```
data\
├── prompts.db                    ← ★主数据库★（你的全部提示词、分类都在这一个文件里）
├── images\                       ← 条目关联的图片（有配图的条目才出现这个文件夹）
└── backup\                       ← 备份目录
    ├── prompts_2026-09-09_08-30-15_123456.db   ← 自动全量备份（每次启动软件生成一份）
    ├── prompts_2026-09-08_23-48-52_494227.db   ← 更早的自动备份
    ├── snapshot_施工前_20260829.db             ← 手动快照（你自己复制的备份，永远不被自动清理）
    ├── prompts_preimport_2026-09-09_09-00-01.db ← 导入前自动快照（导入变更包前自动生成）
    └── incremental\               ← 每日变更包目录
        └── 变更包_DESKTOP-hahaha_2026-09-09_add_1_del_1.json   ← 当日变更包（第 8 章细讲）
```

逐项说明：

| 文件/文件夹 | 是什么 | 能不能删 |
|---|---|---|
| `prompts.db` | 主数据库，**一个文件=全部数据** | 千万别删！删了数据就没了（除非有备份） |
| `data\backup\prompts_日期时间.db` | 每次启动软件时自动生成的"整库快照" | 软件自己按规则清理（默认留最近 30 份），你一般不用管 |
| `data\backup\snapshot_xxx.db`、`*_施工前_*.db` 等 | 手动快照（人肉复制出来的保险） | 软件**永远不**自动删，你自己决定留不留 |
| `data\backup\prompts_preimport_*.db` | 导入变更包前自动生成的安全快照 | 软件**永远不**自动删，可手动清理 |
| `data\backup\incremental\变更包_*.json` | 每天关软件自动生成的"当天变更记录" | 软件默认只保留最近 30 天（设置里可改天数） |

> **想手动做"手动快照"？**（比如大扫除前想留个保险）做法：先**关闭软件**，把 `data\prompts.db` 复制一份到 `data\backup\` 里，改个普通名字，比如 `snapshot_大扫除前_20260909.db`。只要不叫 `prompts_日期_时间.db` 这种标准名，软件永远不会自动删它。
> **怎样手动恢复备份？**：关闭软件 → 用备份的 `.db` 文件**覆盖** `data\prompts.db`（先把原来的 prompts.db 改名留底更稳妥）→ 重新打开软件。

## 4. 第一次启动会发生什么

第一次双击 EXE（或第一次从源码运行）时，软件会依次自动做这几件事，**请耐心等它做完，别中途关窗口**：

1. **自动建库/自动准备数据**：在 `data` 文件夹里生成主数据库 `prompts.db`。
   - 用 EXE 运行时：自动从程序内部复制一份"内置完整模板库"（含 4 个项目类别、10 个根目录、约 2555 条提示词），开箱即用。
   - 从源码运行时：自动建表 + 预置根目录，再自动导入内置手册（会弹出进度条窗口，导完自动消失）。
2. **版本升级时（可选）**：如果检测到内置手册有新版本，会自动做一次"非破坏性合并导入"——只增加新内容，**不会清空你已经存的数据**。
3. **老版本数据迁移（自动弹出）**：如果你的 `data` 里有老版本留下的数据、且根目录还没有归入"项目类别"，会自动弹出"数据迁移向导"帮你整理（详见第 11 章）。如果没有老数据，就不会弹。
4. **设置电脑代号（重要但不急）**：首次使用时，软件自动把"电脑代号"设为本机主机名（例如 `DESKTOP-hahaha`），并记在设置里。
   - 电脑代号干什么用？——给"每日变更包"文件命名用。这样从两台电脑拷来的变更包文件不会重名，能分清"这是哪台电脑产生的"。
   - 在哪里改？——右上角 **⚙ 设置 → 电脑代号**，可随时改成你自己好认的名字（如 `办公室电脑`），改完点"确定"。
5. **注册全局热键与系统托盘**：注册成功后，在任何地方按 `Ctrl+Shift+P` 都能把 PromptSprite 唤到前台并把光标放到搜索框；按 `ESC` 可把窗口藏到托盘。注册失败不影响使用（见 FAQ 12.8）。
6. 底部状态栏会显示统计，例如：`总提示词数 2555｜项目类别 4｜根目录 10｜一级目录 …｜二级目录 …`。

### 5.2 左侧多级书架（项目类别 → 根目录 → 一级 → 二级 → 条目）

数据像书一样分层存放，共五级（中间三级分类书架 + 条目）：

```
项目类别（最高层，如：网上资源收集）
 └── 根目录（如：海外AI绘画案例库）
      └── 一级分类（如：Portrait & People）
           └── 二级分类（如：Street & Urban）
                └── 条目（一条提示词，如：雨夜霓虹街景风格）
```

- **项目类别**（第一列）：给大方向分堆，如"日常学习记录 / 网上资源收集 / 个人梳理资源 / 本人创作作品 / 个人经验总结"。软件内置数据主要在"网上资源收集"里。
- **根目录**（第二列）：项目类别下面的大类，例如"视频 / 图像 / 海外AI绘画案例库 / GPT Image 提示词库"。
- **一级分类 / 二级分类**（第三、四列）：继续往下细分。
- **条目**（第五列）：真正的一条条提示词。每条有一个名称和一串内容字段（第 15 章讲 ①~⑩）。
- 名称太长显示不全？——每列宽度有限，**鼠标悬停到名字上就会弹出完整名称提示**。
- 逐级操作方式：**鼠标单击或悬停**（约 0.2 秒）任意"项目类别/根目录/分类"，右边一列就会自动刷新出它的下级；点一条条目，右侧详情区就显示它的内容。
- 底部状态栏会随着你鼠标悬停的位置，实时显示这一层有多少条提示词。

### 5.3 右侧详情区（看一条、改一条都在这）

选中一条条目后，右边详情区从上到下是：

1. **命令按钮行**（V1.8.0 起顺序与宽度调整）：**☆ 收藏 → ➜ 移动到 → ↔ 关联到 → ⧉ 复制到**（靠左排列，名称已去掉末尾省略号），最右侧是 **✏️ 编辑 / 👁 浏览** 切换开关（见 5.5 节）。
2. **提示词复制行**：📋 复制全部 / 复制中文 / 复制英文（绿色大按钮"💾 保存"、"重置"在这行右侧）。
3. **位置面包屑**（浅色横条）：告诉你这条现在在哪，例如 `🧭 网上资源收集 › 海外AI绘画案例库 › Portrait & People › Street & Urban`。如果一条内容同时挂在多个位置（见 6.6 节"关联到"），这里会列出所有位置，每个关联位置旁边有个"×"可以单独解除。
4. **字段内容区**：一条条目最多有 10 个字段（① 条目名称 + ②~⑩ 内容），每个字段是带彩色边框的独立小卡片，方便区分（第 15 章有字段对照表）。②~⑦ **整组默认折叠成 1 行标题**，点"展开"（或顶部"⏵ 显示全部字段"）才全部展开；⑧⑨ 两个提示词大字段默认折叠成约 6 行高，点"展开"就能看全文。
5. **底部常驻栏**（V1.8.0 起靠右停靠）：最左是一个小图标按钮 **🗂**（一键全部隐藏/全部显示各分类区域，与工具栏"目录隐藏/目录显示"等效）；右侧依次 **🕒 新增历史 ｜ ♻ 删除历史/回收站 ｜ 🗑 删除当前条目**（第 6、7 章细讲）。

> 不同根目录下，右侧字段的多少可能不一样：软件默认"自动"策略，在"视觉风格分类 / 视频 / 图像"类内容下显示全部 10 个字段，在其它根目录下为了突出重点只显示 ①名称、②介绍、⑧中文提示词、⑨英文提示词、⑩图像方案。想全部显示？→ 点详情区顶部"⏵ 显示全部字段"，或 ⚙ 设置 → 详情字段显示 → 改成"全部显示"。

### 5.4 目录隐藏 / 目录显示（V1.8.0 新功能）

左边四列分类（项目类别 / 根目录 / 一级分类 / 二级分类）可以**随你的习惯收起来**，把空间让给"条目 + 详情"：

1. 点工具栏 **🗂 目录隐藏** → 弹出对话框，勾选要隐藏的列（**勾后面的列会自动勾上它前面的列**，保证隐藏的是从"项目类别"起连续的一段）；对话框右侧还有"快捷选项"：**全部隐藏 / 全部显示**，可一键全收或全放。
2. 确认后按钮变成 **🗂 目录显示**；再点开对话框勾选要恢复的列（**勾前面的列会自动带上它后面的列**），确认即恢复。
3. 底部常驻栏最左的小图标 **🗂** 是"一键开关"：点一下全部隐藏，再点一下全部显示。
4. **窗口最小宽度会跟着变**（V1.8.0）：四列全显示时窗口不能小于约 1420 像素宽；隐藏得越多，可缩得越窄（四列全隐藏时最小约 1028，此时只剩"条目 + 详情"两栏，适合把详情区看窄一点或并排摆放）。

> 隐藏只是"不显示"，不影响数据；点它只是界面切换，恢复后分类位置不变。

### 5.5 编辑 / 浏览 切换（V1.8.0 新功能）

详情区右上角的 **✏️ 编辑 / 👁 浏览** 开关用来**防止误改**：

- **✏️ 编辑**（默认）：和以前一样，可以改字段、保存、删除、移动等。
- **👁 浏览**：详情内容变成"只读"，鼠标仍可**选中并 Ctrl+C 复制**；同时"保存 / 重置 / 删除当前条目 / 移动到 / 关联到 / 复制到"会置灰不可点。适合"只想看和抄"的时候。
- 只有"有当前条目"时开关才可用；进入"＋新增条目"或没有选中条目时会自动回到编辑态并置灰。

### 5.6 条目列太长看不全？悬停看"条目名称一览"（V1.8.0 增强）

条目列宽度有限，同屏看不全时：

- 把鼠标**停在条目区约 0.5 秒**，会在条目列左侧浮出 **📋 条目名称一览（共 N 条）** 小窗，一次看全当前分类下所有条目名。
- 浮层里的列表可以滚动：**在条目区滚动滚轮时浮层会跟着同步滚动**；也可以**把鼠标移进浮层**（浮层不会消失）直接拖它的滚动条或滚轮浏览。
- 鼠标移出条目区与浮层后，浮窗自动关闭；切换分类/搜索时也会立即关闭，不会残留旧数据。

## 6. 基本操作

### 6.1 新增一条提示词（两种入口）

**入口 A：主界面就地新增（推荐，最直观）**

1. 在左侧书架逐级选中一个分类（一级或二级分类都可以——软件允许"任一分级分类直接持有本级条目"；也可以先点 📂 未分类 再新增）。
2. 点条目区顶部的绿色按钮"＋ 新增条目"。
3. 右侧详情区变成"新增表单"：在 **① 条目名称（风格名称）** 里输入名称（必填），然后填②~⑩（可只填提示词：⑧中文版、⑨英文版，其余留空也完全没问题）。
   - ③~⑦ 这些补充信息在新增表单里默认折叠成一组，需要时点"展开"再逐项填。
4. 点"💾 保存"。保存后自动回到列表，新条目出现在当前分类里。

**入口 B：✚ 快速新建（连续录几十条时最爽）**

1. 点顶部工具栏"✚ 快速新建"，弹出快速新建窗口。
2. 窗口左边有四列（项目类别 → 根目录 → 一级分类 → 二级分类），**鼠标悬停**即可逐列展开，**不用点击**：滑到某个项目 → 根目录自动刷出；滑到根目录 → 一级分类刷出；再滑到某个分类 → 如果它没有子分类就直接"锁定"它（窗口顶部会显示"已锁定分类：xxx"）。
   - 想存到没有分类的地方？窗口角落有"📂 归入未分类"按钮。
3. 锁定后，光标自动跳进"① 风格名称"输入框，直接输入回车/保存即可入库；表单自动清空，**可以不停手地连续录入**。
4. 录完关闭窗口，主界面自动刷新。

> 锁定状态（🔒）下不能新增；未选中任何分类时主界面的"新增"按钮是灰的，选好位置就亮了。

### 6.2 查看与编辑

- **查看**：左侧点一条条目，右侧详情区即显示。⑧⑨ 提示词内容超出文本框时自动有滚动条；点"展开"查看完整全文（中文/英文提示词不设长度上限）。
- **编辑**：直接在右侧字段里改文字 → 点"💾 保存"。
- **重要防手滑**：如果你在编辑中途去点其它条目，软件会弹窗问：**保存 / 放弃 / 取消**——选"取消"可以回到刚才那条继续改。
- 右侧有个"重置"按钮：把本字段/本次改动还原。
- **记住**：一个条目如果同时"关联"在多个位置（6.6 节），改任何一处保存后，**所有位置的同一内容会一起变**（因为它们本来就是同一条）。

### 6.3 收藏与常用

- 选中条目 → 点详情区"☆ 收藏"（变"★"）。再点一次取消收藏。
- 点顶部"⭐ 常用"，就能看到所有收藏过的条目。收藏状态在回收站恢复时也会一并还原。

### 6.4 搜索

1. 点顶部搜索框（或在软件前台按全局热键 `Ctrl+Shift+P`，光标自动进搜索框）。
2. 输入关键词（支持中文/英文/多个词），**停止输入约 1.5 秒后自动搜索**（V1.8.0 起改为"停顿才查"，避免边打边刷、卡顿）；匹配的是条目的**全部文字字段**。
3. 想立刻出结果：点搜索框右侧的 **🔍** 小图标，或按 **回车**。
4. 清空搜索框 → 恢复刚才的分类视图。

> 为什么要等 1.5 秒？以前每敲一个字符就要把整库搜一遍并重画列表，输入长句时会明显卡顿。现在改成"你停手了我再查"，体验更顺畅。

### 6.5 复制提示词（中文 / 英文 / 全部）

1. 选中条目。
2. 在详情区复制行点按钮：
   - **📋 复制全部** = 名称 + 全部字段一起复制（最常用）。
   - **复制中文** = 只复制⑧中文版提示词。
   - **复制英文** = 只复制⑨英文版提示词。
   - ⑩ 图像获取方案 如果填的是网址，可点它旁边的"打开"按钮直接调浏览器打开。
3. 复制成功后，到 AI 对话框里按 `Ctrl+V` 粘贴即可。

> 隐私提醒：剪贴板内容对你电脑上当前正在运行的所有程序都是可见的（这是 Windows 的机制），请不要复制敏感信息。

### 6.6 条目的"多位置"：关联到 / 复制到 / 移动到

一条提示词可能既适合放"人像"分类、又适合放"夜景"分类。软件给你三种玩法，务必分清：

| 操作 | 是什么 | 后果 | 典型用途 |
|---|---|---|---|
| **↔ 关联到…** | 让"同一条内容"同时出现在多个分类 | 位置变多，但**只有一份**：在任何位置改，其它位置同步变；删除后所有位置一起消失 | 一条内容想被多处查到 |
| **⧉ 复制到…** | 为每个目标分类做一份**独立的副本** | 位置多、内容也多份，各自独立修改（含图片副本）互不影响 | 想在别处改出一版"变体" |
| **➜ 移动到…** | 把当前位置搬到目标分类 | 默认只搬当前这处（其它关联位置保留）；勾选"整体转移"则清空其它位置只留新位置 | 放错地方了，挪个窝 |

- 操作入口：选中条目后点详情区的"➜ 移动到… / ↔ 关联到… / ⧉ 复制到…"，会弹出目标选择窗口（按 项目类别 → 根目录 → 分类 组织，可多选）。
- 在"搜索 / 常用 / 未分类"视图里操作"移动到"，按整体转移处理。
- 想确认一条内容到底在几个地方？看详情区顶部的**位置面包屑**：主位置浅绿色，关联位置浅灰蓝色，每个关联位置都可点"×"单独解除。

### 6.7 删除一条提示词（会先进回收站，别怕）

1. 选中要删的条目。
2. 点详情区底部"🗑 删除当前条目"。
3. 弹窗第一次确认：如果这条同时存在于多个位置，会明确提示"删除后将在全部位置消失"。
4. 弹窗第二次确认：告诉你"确定移入回收站？可随时恢复"。
5. 删除完成。此时它**不是真的没了**，而是进了"♻ 删除历史/回收站"（第 7.3 节），随时能一键恢复原样。

> 为什么删个东西要问两次？——防手滑。数据无价，多点一下"是"的耐心值得。

### 6.8 删除分类（三级保护 + 确认短语）

删除"分类"比删除"条目"危险得多（一个分类下面可能挂着成百上千条），所以软件设了**三级保护**：

**第一级：有下级子分类 → 不允许直接删**
如果这个分类下面还有子分类，弹窗会告诉你"还有 N 个子分类，不能直接删除"。两条路：
- 先逐个处理（删除/移走）下级分类，变成"无子分类"状态再删；
- 或者点【是】进入**级联删除**（把这一整棵分类树连同内容一次性处理）。

**第二级：无子分类 → 安全删除**
弹窗问"确定删除分类【xxx】？它的 N 条本级条目将仅解除在本分类的关联（没有其它位置的条目会转到「未分类」，**条目数据全部保留**）"。点"是"即删除分类本身，但**里面的数据不丢**，只是被"打散"到未分类。

**第三级：级联删除 → 必须输入确认短语 + 最后再确认**
如果你选择把整棵分类树（含全部下级分类）一并删除，软件会要求**手工输入确认短语**才能继续：

1. 弹窗显示将删除哪些分类、有多少条直挂条目将移入回收站；
2. 要求**输入确认短语：「删除全部下级内容」**（这是固定的四个字，必须一字不差）；
3. 短语输对后，还会再弹一次"🚨 最后确认：分类结构将**永久删除**，相关条目移入回收站，确定删除？"；
4. 点"是"才真正执行。分类结构删除后不能从回收站恢复整棵树，但**其中的条目先进了回收站，彻底清除前可恢复**。

> 一句话总结：删分类要过三道闸（有子分类先拦一道 → 删分类本体确认一道 → 级联删除还要输短语+最后确认）。只要你没有"主动输入短语并点两次是"，数据就还在。

## 7. 数据安全

### 7.1 自动全量备份（每次启动自动做，几乎不用你管）

**什么时候做**：每次打开 PromptSprite 时，软件自动把当前整个数据库复制一份到 `data\backup\`，名字像这样：

```
prompts_2026-09-09_08-30-15_483506.db   （prompts_年月日_时分秒_微秒.db）
```

**几条规则（V1.7.0 起）**：

1. **按天去重**：同一天只保留最后一份。哪怕你今天开机 10 次，也不会生成 10 个文件，只留今天最后那次的一份——省空间又不乱。
2. **默认保留最近 30 份**：超出 30 份（约一个月的跨天回滚窗口）后，最老的自动删除。份数可在 **⚙ 设置 → 自动备份保留份数** 里修改（改成比如 60、90 都行，前提是磁盘够）。
3. **只清理"标准命名"的备份**：`prompts_日期_时间.db` 这种才在自动清理范围里。
4. **手动快照（snapshot_*、*_施工前_* 等）永不自动清理**：你亲手复制的保险文件，软件绝对不动。
5. **备份失败有提示**：如果磁盘满了等导致备份失败，启动后底部状态栏会显示"● 备份失败：…"的黄点警告——看到它请尽快清理磁盘或检查 `data` 目录权限。

**怎么用自动备份恢复数据？**：关闭软件 → 挑一个想回到的日期的 `.db` 文件 → 复制去覆盖 `data\prompts.db`（建议先把现在的 `prompts.db` 改名备份一份）→ 重新打开软件。

### 7.2 手动快照：大动作之前的"后悔药"

自动备份是"每次启动"才做的。如果今天你打算做一次大规模整理（比如删一批分类），建议**先做一次手动快照**：

1. 关闭软件；
2. 复制 `data\prompts.db` → 粘贴到 `data\backup\` 文件夹；
3. 把副本改名，例如 `snapshot_整理前_20260909.db`；
4. 重新打开软件，放心干活。

因为名字不是标准备份名，**软件永远不会自动删除它**，你要留多久都行（占空间而已，一份约几 MB 到几十 MB）。

### 7.3 回收站 / 删除历史（恢复 / 彻底删除 / 清空）

入口：详情区底部 **"♻ 删除历史/回收站"**。

这个窗口就是"被删除条目的大本营"，每条显示：**名称、原位置、删除于什么时间、来源**（手动删除 / 级联删除 / 导入同步删除等）。

三个按钮的含义要分清楚：

| 按钮 | 作用 | 后果 |
|---|---|---|
| **↩ 恢复** | 把这条从回收站放回原处 | 原内容、收藏、所在位置全部还原；如果它原来的分类已被删掉，则恢复为"未分类" |
| **彻底删除** | 从回收站移除这一条 | **不可恢复**！连同它关联的图片文件一起释放 |
| **🗑 清空回收站** | 把回收站里所有条目一次性彻底删除 | **不可恢复**！请先确认没有想找回的 |

要点：
- 删除条目时只是"移入回收站"，条目对应的**图片文件也还留着**，直到"彻底删除/清空"才释放。
- 锁定状态（🔒）下这个窗口只读，恢复/删除按钮全部禁用。
- 平时回收站里有几条没处理完全没关系，不占多少空间；建议隔一段时间清空一次。

### 7.4 查看"新增历史"（最近录了什么，一目了然）

入口：详情区底部 **"🕒 新增历史"**。

- 按 **今日 / 近 3 天 / 近 7 天 / 近 30 天 / 全部** 分段查看最近新增的条目。
- 每条都可以一键复制提示词（复制中文 / 复制英文 / 复制全部），方便速取、自查工作量。
- 只读窗口，锁定状态下同样可看。

## 8. 每日"变更包"

> 这一章是 V1.7.0 的重头戏，也是新手最容易懵的地方。我们拆成五个小问题慢慢讲：**是什么？什么时候生成？文件名怎么看？怎么拷到另一台电脑合并？导入时那几个选项到底选哪个？**

### 8.1 它是什么？什么时候自动生成？

**是什么**：PromptSprite 每天帮你记一笔"账"——把**今天这一天里**你对数据做过的所有改动（新增了哪些、删除了哪些、改动了哪些分类）打包成一个 JSON 文件，叫**当日变更包**。它是"当天变化"的记录，不是全量数据。

> 打个比方：全量备份像"每天给整本书拍照"，变更包像"每天记一行日记：今天加了 3 页、撕了 1 页"。

**什么时候自动生成**：**每次正常关闭软件时**自动执行（也就是"正常使用时自动生成"，你不用点任何按钮）。

- 存储位置：`data\backup\incremental\`
- 当天如果**没有任何变化**（没新增、没修改、没删除），就不会生成新文件（这是正常的）。
- 当天有变化、后来又改了：关软件时会**重新生成**同一个"当日文件"，永远保证**每台电脑每天只有一个变更包**，内容=当天全部变更。
- 保留规则：默认只保留最近 **30 天**（在 ⚙ 设置 → 变更包保留天数 可改）。老版本软件生成的"增量_xxx.json"文件也会被一起按 30 天清理。

### 8.2 文件名的含义：`变更包_{电脑代号}_{日期}_add_{N}_del_{M}.json`

完整格式：

```
变更包_电脑代号_日期_add_新增条数_del_删除条数.json
```

举三个真实例子：

| 文件名 | 一眼能看出什么 |
|---|---|
| `变更包_DESKTOP-hahaha_2026-09-09_add_3_del_0.json` | 电脑 DESKTOP-hahaha 在 09-09 当天**新增/修改了 3 条，没删任何条目**（纯新增包，安全） |
| `变更包_DESKTOP-hahaha_2026-09-09_add_1_del_1.json` | 当天**新增 1 条、删了 1 条**（有增有删的混合包） |
| `变更包_DESKTOP-053MORJ_2026-09-08_add_0_del_1380.json` | 当天**一条没加、却删了 1380 条**——这是"**纯删除包**"，俗称**负增量**（见 8.4 节的警告），拿到这种文件要格外小心！ |

数字代表什么：

- `add_` 后面的数字 = 当天**新增/修改的条目条数**（按"条"计）。说明：目前软件判断"是不是同一条"靠内容比对，"修改一条"在变更包里会表现为"新增一条同内容的新条目 + 保留原条目"。
- `del_` 后面的数字 = 当天**删除的条目条数**。
- **分类、根目录的增减不算进文件名**（它们记在文件内部的摘要 summary 里，导入预览时会显示出来）。
- 一句话：**光看文件名就能判断这个包是"会让我变多"还是"会让我变少"**——这是 V1.7.0 专门吸取 9-8 事故教训加的（以前叫"增量备份"，让人误以为只会加数据）。

### 8.3 怎么把这个文件拷到别处 / 给别人

有两个入口，效果不同：

1. **⇧ 导出 → 导出当日变更包文件到…**
   - 只导出"今天"自动生成的那个变更包文件，可存到 U 盘/网盘/发给另一台电脑。
   - 导出前会先弹一个小窗"对账"：显示文件名、新增/修改几条、删除几条。
   - ⚠️ **负增量警告**：如果今天只删没加（`add_0`、`del_>0`），会弹红色警告窗"该变更包为当日仅删除数据的‘负增量’包，请谨慎分发/导入！"——意思是：这个包拷给别人，**只会删掉对方的数据，不会给对方加任何东西**。看清楚再发。
2. **⇧ 导出 → 变更包数据导出 Excel… / HTML…**
   - 选一个变更包文件，把它转成 Excel 或网页，方便**打开浏览**里面的内容、或发给不想装软件的人看（转换过程在临时库里进行，不影响你当前数据）。

### 8.4 换机合并：把变更包导入另一台电脑/副本（重点！）

**场景**：你办公室电脑（代号 `OFFICE-PC`）今天录了 20 条新提示词，关软件时自动生成了 `变更包_OFFICE-PC_2026-09-09_add_20_del_0.json`。晚上回家想在**家里电脑**上也看到这 20 条。

**操作步骤**：

1. 在办公室电脑：⇧ 导出 → 导出当日变更包文件到… → 把文件存到 U 盘（或发给自己）。
2. 回家打开家里电脑上的 PromptSprite。
3. 点顶部 **⇩ 导入** → **导入变更包…（新增/删除合并）**，选择 U 盘里那个 json 文件。
4. 软件先弹出**导入预览**窗口，把包里的"账"念给你听：
   > 来源电脑：OFFICE-PC　　日期：2026-09-09
   > 包内新增/修改：条目 20、分类 2、根目录 0
   > 包内删除清单：条目 0、分类 0、根目录 0（或"本包不含删除清单"）
5. 确认无误后，按下面 8.5 节的两条选择来勾选，点"开始导入"。
6. 完成：底部提示导入结果；回到书架就能看到新条目。

**重要提醒（第 9-8 事故的教训，务必看）**：变更包≠只会加数据。它可能是个**删除包**（负增量）。如果你把自己 9 月 1 日的老全量库，直接导入一个 9 月 8 日的删除包，软件会按删除清单把"内容相同"的条目从老库里删掉——条目数不升反降（真实测试中 3987 条被删到 2607 条）。**所以导入前一定要看预览**，并想清楚下面两个问题。

### 8.5 导入向导的两个选择（V1.7.0，全用大白话解释）

预览窗口里真正要你决策的，是**两个正交的选项**，互相不冲突：

**第①个选择：要不要"导入并合并包内新增/修改条目"？（一个复选框，默认已勾选）**
- 勾上 = 把包里的新内容加进这台电脑（推荐）。
- 不勾 = 只处理删除清单，不加任何新内容（极少用）。

**第②个选择：包里的"删除清单"怎么处理？（三选一，单选按钮）**

| 选项 | 大白话 | 什么时候选 | 需要输入确认短语吗 |
|---|---|---|---|
| **忽略删除（不删任何现有数据，推荐）** | 假装没看见删除清单，一条都不删，只进新的 | **默认推荐。** 你不确定这台电脑是否同步过对方的历史删除时，永远选它最安全 | 不需要 |
| **正常应用删除（把清单中内容从本库删除，需确认）** | 让本库"跟上"来源机：凡是清单里点名要删的内容，只要本库里有相同内容，就一起删掉（先移入回收站，可恢复） | 这台电脑和来源机**长期保持同步**、你想让两台完全一致时 | 需要输入短语「**确认删除**」 |
| **逆向恢复已删除数据（把清单中携带快照的内容重新导入，需确认）** | 反向操作：把"当初被删掉的内容"重新加回来（救援功能） | 你想找回数据、且包里带被删内容的完整快照时（见第 9 章）。**若包里没带快照，这个选项是灰的**，提示只能靠回收站/历史备份 | 需要输入短语「**恢复删除**」 |

**三个必须懂的安全机制**：

1. **确认短语 = 最后一道闸**。选"正常应用删除"要亲手输入「确认删除」；选"逆向恢复"要亲手输入「恢复删除」。输错或取消 = 不执行。这是逼你在点确定前再想一遍。
2. **导入前自动快照 = 后悔药**。只要执行"应用删除"或"逆向恢复"，软件都会**先自动生成一份 `prompts_preimport_日期时间.db`** 放在 `data\backup\` 里，然后再动手。万一后悔：关闭软件 → 用这个文件覆盖 `data\prompts.db` 就能回到导入前。这个文件以 `prompts_preimport_` 开头，**不会被自动清理**。
3. **落后提示 = 危险预警**。如果目标电脑的最后同步时间早于变更包日期（说明这台电脑可能还没同步过来源机的历史删除），预览窗口顶部会出现红字：
   > ⚠ 提示：目标库最后同步时间早于本变更包日期，可能尚未同步来源机的历史删除；如无把握请把删除处理选为"忽略删除"。
   看到红字，乖乖选"忽略删除"就对了。

**还有两个补充说明**：
- 同步删除的内容**先进回收站**（可恢复、图片保留）；但**被删的分类结构**是直接删除的，不随回收站恢复。
- 导入普通"JSON 备份"如果发现文件其实是个变更包/带删除清单，软件会自动改走这个导入向导，不会让你盲导。

### 8.6 一个完整的"灾难救援"小例子（体会负增量/逆向恢复）

假设你的数据出过这种事：

- 9 月 1 日：你有 2500 条（只剩这一天的全量备份）。
- 9 月 4 日：加了 1000 条 → 3500 条。
- 9 月 5 日：当天新增 100 条、又删掉了 9 月 4 日那批里的 500 条 → 当天变更包文件为 `add_100_del_500`。
- 9 月 9 日：系统坏了，你手里只有 9 月 1 日的全量备份和 9 月 5 日的变更包。

问：现在最多能恢复到多少条？

答：**2600 条**。做法：先导入 9 月 1 日全量库，再导入 9 月 5 日变更包时选"①合并新增"+"②忽略删除"。为什么不是 3100？因为那被删的 500 条在 9 月 1 日的备份里本来就不存在（它们是 9 月 4 日才加的），"删除清单"在你库里一条都命中不了，不会变少；而真正缺的，是 9 月 4 日新增、9 月 5 日**没删**的那 500 条——它们不在 9 月 1 日的全量里、也不在 9 月 5 日的变更包里（9 月 5 日没动它们），**任何魔法都补不回来**，只能靠 9 月 4 日的备份/变更包/删除那台机器自己的回收站。

**结论（长期正确姿势）**：
1. 平时让软件自动做全量备份（30 份）+ 每日变更包（30 天）都开着，别关；
2. **定期**把"全量 JSON 导出"或备份 `.db` 文件复制到网盘/U 盘（异机异地最保险）；
3. 有了"某一天的全量 + 之后每一天的变更包"，理论上可以**向前重建**到任意一天；
4. "逆向恢复"是极端情况下的补救手段，不是日常主路径。

## 9. 变更包携带被删快照

### 9.1 它是干什么的？

开关位置：**⚙ 设置 → 变更包携带被删快照**（默认**关闭**）。

- **关闭（默认）**：变更包的删除清单里只记录被删条目的"名字 + 内容指纹"，**不含完整内容**。好处是文件小、而且"已删除的内容"不会跟着包到处分发；代价是拿到这个包的人无法逆向恢复（只能靠目标库自己的回收站/历史备份）。
- **开启**：软件在生成每日变更包时，把**被删条目的完整内容（快照）也塞进包**。这样把包导入其它电脑时，就能用第 8.5 节的"逆向恢复"把当初删掉的数据重新加回来。

### 9.2 开启它，界面上的红字会告诉你代价

设置窗口里这个开关下面有一行**红色小字**，原文大意：

> ⚠ 开启后变更包内会包含"已删除"的内容（体积增大、含敏感数据），但可在导入时使用"⑤ 逆向恢复"找回被删数据。

翻译成大白话，你要权衡三点：

1. **体积变大**：快照是完整内容，会明显增大包文件；
2. **隐私风险（最关键）**：如果当初删除这批数据就是为了"清理私人内容/防止泄露"，那开着这个开关 = 把"你已删除的隐私"又装回包里带走分发——**负增量包会变成隐私泄露包**。所以默认关闭；
3. **可能找回"当时有意删除"的数据**：逆向恢复会把当初**故意删掉**的内容也加回来。所以"逆向恢复"执行前要输入确认短语「恢复删除」，弹窗里也明说了"可能包含当初有意删除的数据"，想清楚再输。

**给你的建议**：日常**保持关闭**即可。真遇到"只有变更包、没有别的备份、还想找回被删内容"的极端情况，再临时开启让它生成一次携带快照的包，用完记得关回去。

## 10. 数据比对

### 10.1 这是干什么的？

V1.7.0 新增的**只读诊断**功能：拿"当前的数据"和"某一天自动备份的 \*.db 文件"比一比，一目了然地看出：

- 备份里有、现在没有了（= 这段时间被删的）；
- 现在有、备份里没有（= 这段时间新加的）；
- 分类/根目录/项目类别的增减；
- 条目内容变化（按名称 + 内容比对）。

### 10.2 怎么用

1. 点 **⇩ 导入** → 菜单最下面 **数据比对…（与备份 \*.db）**。
2. 在文件选择框里挑一个备份文件，例如 `data\backup\prompts_2026-09-01_...db`（自动备份和手动快照都是 \*.db，都能比）。
3. 窗口会先给"差异概览"（新增多少、删除多少、当前共多少条、备份共多少条），下面是**差异明细列表**（每条显示：差异类型 / 名称 / 所在分类链）。
4. 可点"导出差异报告（HTML）"，存成一个网页文件方便留存或发给别人看。

**安全保证**：
- **全程只读**：软件先把要比较的备份复制到临时文件再打开，**绝不写入你的主数据库**，放心用；
- 比较的条目按"内容指纹"判断是否同一内容，只看差异、不改任何东西；
- 锁定状态下此功能不可用（因为它需要读取，且属于菜单诊断功能）。

**用途举例**：你怀疑"导入某个变更包后数据变少了？"——不必瞎猜，用这个功能把当前库和一个导入前的自动备份（或导入前快照 `prompts_preimport_*.db`）比一下，少了哪些条目、哪些分类，列得清清楚楚。

## 11. 老版本数据迁移

如果你是 PromptSprite 老用户，数据是老版本结构（根目录-一级-二级，还没有"项目类别"这一最高层），升级到新版本后软件这样处理：

**第 1 步：数据库自动升级（不用你管）**
打开软件时，程序会自动检查并补全新版需要的表/字段（幂等迁移，可反复打开），老数据不会丢。

**第 2 步：根目录归属整理（可能需要你点几下）**
老版本的根目录没有归入"项目类别"，会暂时显示在"项目类别"列最底部的"🗂 未分配"里。此时：

- 启动时若检测到存在"未分配"的根目录，会自动弹出 **数据迁移向导**（若你上次点过"取消"，之后不再自动弹，但可手动打开）；
- 手动打开：**⇩ 导入 → 数据迁移向导…**。

**在向导里做什么**：
1. 表格列出所有未归属的根目录，每一行右边有个下拉框让你选"归入哪个项目类别"（**默认值已按软件内置的映射表帮你预填好了**，多数情况直接点执行即可）。
2. 点"执行迁移"：已选择的按你选的归入；没匹配映射的默认归入"未明确分类"。
3. 点"取消"：什么都不改（根目录继续留在"未分配"，以后随时可再开向导）。

> 注意：无论怎么选，**你的条目数据都不会丢失**，只是根目录的"归属大堆"变了。迁移完成后，"未分配"消失，所有根目录都进了某个项目类别。

## 12. 常见问题 FAQ

### 12.1 我找不到 `data` 文件夹在哪里？

- **用 EXE**：`data` 就在 `PromptSprite.exe` 的**同一个文件夹**里。如果你是通过"快捷方式"启动的，请去快捷方式指向的**真正存放 EXE 的文件夹**里找。
- **从源码运行**：`data` 在项目根目录（和 `app` 文件夹平级）。
- 还找不到？打开软件，右上角 ⚙ 设置 → ℹ 关于，里面会显示"程序路径"，`data` 就在那个路径下。

### 12.2 换电脑/换文件夹后，为什么数据是空的（全新模板）？

因为你只复制了 EXE，没复制 `data`。软件在没有任何 `data` 的情况下首次运行，会自动生成内置模板库（全新数据）。

**正确做法**：把**整个文件夹**（含 `data`）一起拷走。保险起见，平时就把 `data` 里的 `prompts.db` + `backup` 文件夹定期备份到网盘/U 盘。

### 12.3 误删了数据怎么办？

分几种情况，按顺序试：

1. **刚删的条目**：详情区底部 **♻ 删除历史/回收站** → 找到那条 → 点"↩ 恢复"（内容/收藏/位置原样回来）。
2. **删了分类（安全删除）**：条目没丢，只是被"打散"到 **📂 未分类** 里，去那里找。
3. **级联删了一大片 / 导入删了一大批**：
   - 回收站里应该躺着那些被删条目，先恢复；
   - 如果是在"导入变更包"之后发生的，用导入前自动快照 `data\backup\prompts_preimport_*.db` 覆盖 `prompts.db` 整体回滚（第 8.5 节）；
   - 再不行，用启动自动备份里**最近的一份** `prompts_日期.db` 回滚（第 7.1 节）。
4. 都没救回来？——那就只剩"彻底删除"之前你手动复制出去的备份了。**再次强调：重要数据请定期异机备份。**

### 12.4 导入一个包之后，条目数反而变少了？！

先别慌，按下面三步排查：

1. **看预览数字（最重要）**：V1.7.0 起导入"变更包"前必有预览窗，会明说"包内删除清单：条目 X、分类 Y"。如果你导入的是一个 `add_0_del_1380` 之类的**纯删除包（负增量）**，条目变少是**符合预期的**——它本来就是个"删除清单"，不是"增加包"。不想删，就选"忽略删除"再导一次。
2. **看回收站**：执行了"正常应用删除"的条目先进回收站（可恢复）；还有导入前自动快照 `prompts_preimport_*.db` 可整体回滚。
3. **看是不是显示问题**：数据其实没少，只是
   - 你现在停在"搜索/常用/未分类"视图里，回到 **项目类别列逐级点** 再看；
   - 或者一些字段因为"详情字段显示=自动"被隐藏了（第 5.3 节）——在 ⚙ 设置里改"全部显示"即可看到全部字段，数据一直还在库里。

### 12.5 为什么有些条目的"③~⑦"字段看不到？

多半是"详情字段显示"设成了**自动**（默认）：软件在部分根目录（视觉风格分类/视频/图像以外）下只突出 ①名称、②介绍、⑧中文、⑨英文、⑩图像方案。想全部看到/编辑：⚙ 设置 → 详情字段显示 → **全部显示**。（新增时想填 ③~⑦，点表单里的"展开"那一组即可。）

### 12.6 删了条目/图片会一起没吗？

不会立刻没。删除条目 = 移入回收站，**图片文件保留**；只有你在回收站里点"彻底删除"或"清空回收站"时，图片文件才会一并释放（释放后不可恢复）。另外"⧉ 复制到"会为副本生成**独立的图片副本**。

### 12.7 为什么点删除/保存/导入都是灰的、点不动？

因为你开着 **🔒 锁定**（按钮显示红色"🔓 已锁定"）。锁定状态下软件只允许查看、搜索、复制，所有写操作（新增/编辑保存/删除/移动/导入/快速新建）一律禁用——这是防误操作保护。点一下"锁定"按钮解锁即可。

### 12.8 全局热键 `Ctrl+Shift+P` 没反应？

热键注册失败常见原因：

- 热键被其它软件占用；
- 权限不足（普通权限下某些环境注册不了全局键）——**以管理员身份运行一次**试试；
- 被杀毒软件拦截——把软件加入白名单。

热键失败不影响正常使用（点窗口、用按钮都行）。

### 12.9 软件打不开 / 启动闪退 / 没反应？

按顺序排查：

1. 路径是否含中文/特殊字符 → 放到纯英文路径（如 `D:\PromptSprite`）；
2. 杀毒软件拦截 → 加入白名单后重新解压/运行；
3. EXE 是否被下载工具损坏 → 重新下载；
4. 从源码运行时依赖没装好 → 手动执行 `pip install -r requirements.txt`；
5. 查看 `data` 所在磁盘剩余空间是否足够。

### 12.10 状态栏出现"● 备份失败"？

说明这次启动的自动备份没成功（最常见是磁盘空间不足或 `data\backup` 写入权限问题）。请清理磁盘空间或检查目录权限，下次启动软件会自动重试。

### 12.11 找不到今天的"变更包"文件？

当天没有任何数据变化（没新增/修改/删除），关软件时不会生成文件，这是正常的。随便新增一条再正常退出，就能在 `data\backup\incremental\` 看到今天的 `变更包_*.json` 了。

### 12.12 Excel 文件太大导入很慢/卡？

Excel 导入已用流式读取方式处理，但超大文件仍需要时间。文件特别大时建议拆分成几个文件分批导入，或改用 JSON 格式导入。

## 13. 版本说明（V1.8.0 / V1.7.0）

### 13.1 V1.8.0（2026-09-10）——界面与体验修订

本轮**不改数据格式、不改数据库结构**，全部是界面与交互的完善（数据完全兼容，直接升级即可）：

1. **工具栏重排与瘦身**：按钮顺序固定为 锁定 → 目录隐藏/目录显示 → 无类条目 → 常用 → 新建 → 导入 → 导出 → 设置 → 搜索框；搜索框移到最右端（最小 10 个汉字宽，随窗口变宽）；各按钮宽度收紧，界面更紧凑。
2. **"项目列"→"目录隐藏 / 目录显示"（功能升级）**：由原来只能收起"项目类别"一列，改为可**任选隐藏 项目类别/根目录/一级/二级（连续前缀）**，对话框内提供"全部隐藏 / 全部显示"快捷项；底部常驻栏新增 **🗂** 小图标可一键全隐/全显（见 5.4 节）。
3. **窗口最小宽度动态化**：四列全显示时最小约 1420；隐藏得越多可缩得越窄（四列全隐藏约 1028），方便把窗口摆窄、只看"条目 + 详情"。
4. **搜索改为"停顿 1.5 秒后再查"**：解决"刚敲一个字就整库刷新、输入长句卡顿"的问题；新增右侧 **🔍** 图标点击即搜，回车仍可立即搜索（见 6.4 节）。
5. **新增"✏️ 编辑 / 👁 浏览"切换**：浏览态详情只读、可选中复制，编辑类按钮置灰，防误改（见 5.5 节）。
6. **详情区命令条调整**："移动到 / 关联到 / 复制到"去掉名称末尾省略号、整体靠左排列并紧挨"编辑/浏览"；"编辑/浏览"移到最右；"☆ 收藏"移到最左且宽度贴合文字；"保存 / 重置 / 复制全部 / 复制中文 / 复制英文"宽度微调，保证任何窗口宽度下文字都完整不裁切。
7. **条目列悬停"条目名称一览"修补**：浮层不再"鼠标一移开就消失"——可把鼠标移进浮层滚动；在条目区滚动滚轮时浮层也同步滚动（见 5.6 节）。
8. **详情区字段折叠形态统一**：②~⑦ 整组默认折叠为 1 行（不再占空白），点"展开"/"⏵ 显示全部字段"全部展开；⑧⑨ 各自独立"展开"。
9. **底部常驻栏按钮重排**：由"删除当前条目在最左"改为靠右停靠（🕒 新增历史 ｜ ♻ 删除历史/回收站 ｜ 🗑 删除当前条目），最左留出 🗂 一键显隐图标。
10. **"未分类"按钮更名"无类条目"、"快速新建"更名"新建"**（仅名称，功能不变）。

### 13.2 V1.7.0（2026-09-08）版本说明

V1.7.0（2026-09-08）在 V1.6.0 基础上的主要变化：

1. **"增量备份"升级为"每日变更包"**（名字也改了）
   - 文件名带增删计数：`变更包_{电脑代号}_{日期}_add_{N}_del_{M}.json`，纯删除（负增量）包一眼可辨；
   - 包内格式升级（带 summary 摘要），老格式文件（含旧"增量"文件）仍然兼容可导入；
   - 设置、菜单、说明文案全面改为"变更包"。
2. **导入安全向导（防"导入即大量删数据"事故）**
   - 导入前先预览：来源电脑/日期/将新增多少/将删除多少；
   - 两个正交选择：①是否合并包内新增/修改；②删除清单处理（忽略删除 / 正常应用删除 / 逆向恢复），后两者需输入确认短语；
   - 目标库落后于包日期时红色预警；导入前自动生成 `prompts_preimport_*.db` 快照可回滚。
3. **同步删除先进回收站**：被"变更包"同步删除的条目先入回收站（可恢复、图片保留），不再物理直删。
4. **导入性能大幅提升**：万级条目库导入从原来 4 分钟+ 降至约 10 秒量级，并带进度显示。
5. **自动全量备份策略更新**：按天去重（同日只留一份），默认保留 30 份（原 5 份），可在设置里修改；只清理标准命名备份，手动快照永不清理。
6. **新增"数据比对（与备份 \*.db）"**：只读对比当前库与任意备份库的差异，可导出 HTML 差异报告。
7. **新增"变更包携带被删快照"开关（默认关）与"逆向恢复"**：开启后变更包可携带被删条目完整内容，供导入时逆向恢复（输入短语「恢复删除」）。
8. 设置窗口新增"自动备份保留份数""变更包携带被删快照"两项。

（V1.6.0 及更早版本的功能——初始导航、回收站/删除历史、新增历史、条目多位置、就地新增、删除分类三级保护、四级书架、全局热键等——在 V1.7.0/V1.8.0 中均完整保留，本说明书前面各章已一并介绍。）

## 15. 附录

### 附录 A：一条条目的 ①~⑩ 字段都是什么？

| 编号 | 字段名 | 大白话 | 必填？ |
|---|---|---|---|
| ① | 条目名称（风格名称） | 这条提示词的"名字"，如"赛博朋克雨夜街景" | 必填 |
| ② | 介绍 | 这条内容/风格的文字介绍 | 选填 |
| ③ | 溯源 | 这个风格/案例的来源出处 | 选填 |
| ④ | 核心特征 | 抓住风格的关键特征描述 | 选填 |
| ⑤ | 应用场景 | 适合用在什么场景 | 选填 |
| ⑥ | 代表作 | 代表作品/例子 | 选填 |
| ⑦ | 代表高清配图 | 配图描述 | 选填 |
| ⑧ | 中文版提示词 | 中文的完整提示词文本（大字段，可折叠展开） | 建议至少填 ⑧/⑨ 其一 |
| ⑨ | 英文版提示词 | 英文的完整提示词文本（大字段，可折叠展开） | 同上 |
| ⑩ | 图像获取方案 | 生成/获取该图像的方案或网址（可"打开"直达） | 选填 |

> 字段②~⑩是独立的彩色卡片块；②~⑦ **整组默认折叠为 1 行标题**（点"展开"或顶部"⏵ 显示全部字段"全部展开），⑧⑨ 各自默认收起成约 6 行、点自己的"展开"看全文。提示词长度不设上限（数据库为超长文本类型）。

### 附录 B：术语小词典（小白先看这个）

| 术语 | 意思 |
|---|---|
| 提示词 / Prompt | 你写给 AI 的指令文本，是软件里被管理的主角 |
| 条目 | 一条完整的提示词记录（含名称和 ①~⑩ 字段） |
| 项目类别 | 最高一层分类（如"网上资源收集"） |
| 根目录 | 第二层大类（如"海外AI绘画案例库"） |
| 一级/二级分类 | 第三、四层细分（如 Portrait & People / Street & Urban） |
| 未分类 | 还没有归入任何分类的条目集合 |
| 常用 | 你收藏（☆）过的条目集合 |
| 锁定 🔒 | 只读模式：只许看和复制，禁止一切改动 |
| 全量备份 | 整个数据库的一份拷贝（\*.db 文件） |
| 变更包 | 某台电脑某一天全部变更的记录文件（\*.json，原名"增量备份"） |
| 负增量 / 纯删除包 | 只有删除没有新增的变更包（文件名 `add_0_del_N`） |
| 快照 | 某一时刻数据的定格拷贝；自动备份、手动快照、导入前快照都是快照 |
| 回收站 / 删除历史 | 被删条目的暂存处，可恢复、可彻底删除、可清空 |
| 逆向恢复 | 把删除清单里带快照的内容反向加回来（救援功能，需短语「恢复删除」） |
| 导入前快照 | 导入变更包前自动生成的安全备份（`prompts_preimport_*.db`），用于回滚 |
