# PromptSprite（提示精灵）软件安装使用说明书（V3.0 修订版）

> 版本：V3.0（2026-08-18）
> 适用对象：完全零基础的小白用户
> 一句话：这是一款帮您分类管理"AI 提示词"（Prompt）的本地小软件，数据全在您自己电脑里，**绝不联网、绝对隐私**。
> 前版：V2.0（2026-08-18）

---

## 一、软件能做什么？

把您积累的 AI 提示词整理成一个"分类书架"：

- **左边三列**：根目录 → 一级分类 → 二级分类，像文件夹一样层层点开；
- **中间**：条目列表（卡片/列表两种显示方式）；
- **右边**：条目详情（9 个字段，含中英文提示词，可一键复制、可编辑、可配图）；
- **快速新建**：鼠标滑过分类即锁定，直接输入保存；
- **搜索 / 收藏 / 未分类**：快速找到常用内容；
- **自动备份**：每次启动自动备份，最多保留 5 份，坏了能找回。

> **V3.0 新增亮点**：
> - 软件已内置 **3800+ 条**优质 AI 绘画提示词（12 个根目录：海外案例库、精选案例、GPT Image 提示词库、AI 生图提示词大全、手绘插画、SDXL 摄影风格、时尚搭配速查表等），开箱即用；
> - 底部**状态栏动态统计**：鼠标悬停到哪个位置，就显示哪个位置的数据量；
> - **设置入口**：可记住窗口大小、切换卡片/列表视图、控制详情字段显示；
> - 详情"⑩ 图像获取方案"若填了网址，旁边会出现"打开"按钮，一键直达。

## 二、安装说明

### 2.1 获取软件

拿到单个文件 **`PromptSprite.exe`**（约 21MB），**无需安装**。若为压缩包请先解压到任意文件夹（建议 `D:\PromptSprite\`，**不要**放在压缩包里直接运行）。

### 2.2 启动与首次运行

1. **双击** `PromptSprite.exe`；
2. 稍等 1~3 秒出主界面；
3. 首次运行自动在 **EXE 同目录**生成 `data\` 文件夹，并自动复制软件**内置的完整最新数据库**（含 3800+ 条提示词、12 个根目录），开箱即用（2026-08-18 第023条起）。

> **重要（数据位置）**：软件所有数据保存在 **EXE 所在文件夹的 `data\` 子目录**里：
> - `prompts.db`：主数据库（您的全部内容）；
> - `backup\`：自动备份（最近 5 份）；
> - `images\`：您给条目关联的图片。
>
> **换电脑/换位置**时请**连同整个文件夹一起拷贝**，或使用"导出 JSON"搬家（见 §6.4）。

### 2.3 Windows 拦截与杀毒白名单

- 首次运行可能提示"Windows 已保护你的电脑"→ 点 **"更多信息" → "仍要运行"**（软件纯本地、无网络，可放心）；
- 全局热键 `Ctrl+Shift+P` 需要系统级监听：若无效，请将 `PromptSprite.exe` 加入杀毒软件白名单，或以管理员身份运行。

### 2.4 卸载

删除 `PromptSprite.exe` 即可；同时删除同目录 `data\` 可清除全部数据（**删除前请先导出 JSON 备份**，见 §6.3）。

## 四、基本操作（一步一步来）

### 4.1 查看提示词（第一次使用请从这里开始）

1. 鼠标移到左侧**根目录**（如"图像"），稍等自动进入；
2. 移到**一级分类**（如"手绘插画"），再移到**二级分类**（如"3D与动画风格"）；
3. 中间**条目区**出现该分类下的所有提示词卡片；
4. 鼠标移到某张卡片上，右侧**详情区**立即显示这条提示词的全部内容。

### 4.2 详情区字段说明

| 字段 | 说明 |
| ---- | ---- |
| ① 名称 | 提示词标题（可改） |
| ② 介绍 | 一句话说明 |
| ③ 溯源 | 提示词出处/灵感来源 |
| ④ 核心特征 | 风格关键特征 |
| ⑤ 应用场景 | 适合用在什么地方 |
| ⑥ 代表作 | 代表作品/参考 |
| ⑦ 代表高清配图 | 配图文字描述 + 关联图片 |
| ⑧ 中文版提示词 | **中文提示词（最重要）** |
| ⑨ 英文版提示词 | 英文提示词 |
| ⑩ 图像获取方案 | 生成参数/网址（填网址会出"打开"按钮） |

> **字段自动隐藏**：查看"视觉风格分类/视频/图像"时 9 个字段**全部显示**；查看"计算机编程/音频/文学/学术/专业报告"等根目录时自动隐藏 ③-⑦，只突出 ⑧⑨⑩ 提示词内容。您也可以在"⚙ 设置"里改成"全部显示"或"精简"。

### 4.3 复制提示词（最常用）

右侧"⑧/⑨ 提示词"一行有三个按钮：
- **📋 复制全部**：中英文一起复制；
- **复制中文** / **复制英文**：单独复制。

点一下即复制成功，到任何地方 `Ctrl+V` 粘贴即可。

### 4.4 搜索（找东西最快的办法）

- 顶部**搜索框**输入关键词，下方实时过滤，所有字段都会匹配（名称/介绍/中英文提示词等）；
- **清空**搜索框恢复原来的列表；
- 任何界面按 **`Ctrl+Shift+P`** 都能把软件唤出来并自动聚焦搜索框；
- 按 **`ESC`** 把软件隐藏到右下角托盘，托盘图标右键可"显示主界面/退出"。

### 4.5 快速新建（自己添加提示词）

1. 点顶部 **"✚ 快速新建"**，弹出新建窗口；
2. 鼠标在"根目录→一级→二级"上依次悬停（每层 0.2 秒自动锁定），窗口左上角显示"**✔ 已锁定：xxx**"；
3. 光标自动跳入"① 风格名称"输入框，填名称（**其余字段均可留空**，建议把提示词填进 ⑧ 或 ⑨）；
4. 点 **"💾 保存"**，表单清空可连续录入；"📂 归入未分类"按钮可先不选分类保存。

### 4.6 编辑 / 收藏 / 删除 / 移动

- **编辑**：在详情区直接修改 → 点"💾 保存"；"重置"放弃本次修改；切换条目时若有未保存内容会弹窗（是=保存 / 否=放弃 / 取消=返回）；
- **收藏**：详情区点"☆ 收藏"变"★ 已收藏"，点顶部"⭐ 常用"可集中查看；
- **删除**：所有删除都**弹两次确认**，防止误删；删除分类时，它下面的条目**自动转入"未分类"**（不丢数据）；删除根目录只是"解除关联"，分类和条目还在；
- **移动**：鼠标**右键**点条目 → "移动到分类…" → 弹出树形选择框选目标位置（也可点"📂 移入未分类"）；
- **锁定**：点"🔒 锁定"后所有删除功能变灰禁用（防止小孩/手滑误删），再点"🔓 已锁定"解除。

### 4.7 管理分类（新建/重命名/删除）

- 三列顶部都有"**➕ 新增**"按钮（新增根目录/一级/二级）；
- **右键**点某个分类 → 菜单：新增子分类 / 重命名 / 删除。

### 4.8 给条目关联图片

1. 选中条目，详情区"⑦ 代表高清配图"下方；
2. 点"**选择图片…**"选一张本地图片 → 自动复制到 `data\images\` 并显示预览；
3. "**移除图片**"解除关联。图片只保存在本机。

### 4.9 设置（⚙）

点顶栏"⚙ 设置"：
- **记住窗口大小**：开启后关闭时保存窗口大小，下次启动恢复；
- **默认视图模式**：条目区默认"卡片"还是"列表"；
- **详情字段显示**：自动（按根目录）/ 全部显示 / 精简。

## 五、导入导出数据（搬家、批量编辑、分享）

顶部"**⇩ 导入**" / "**⇧ 导出**"为下拉菜单：

| 菜单 | 用途 | 小白怎么用 |
| ---- | ---- | ---- |
| 导入 JSON 备份 | 恢复完整备份 | 换电脑/还原时选备份文件 |
| 导入 Excel | 表格批量导入 | 把 .xlsx 表格直接导进来 |
| 导入 Markdown 手册 | 解析 MD 手册 | 指定目标根目录（默认"视觉风格分类"） |
| 导出全部/当前 JSON | 完整备份 | 定期备份就选这个 |
| 导出全部/当前 Excel | 14 列表格 | 用 WPS/Excel 打开批量编辑后再导入 |
| 导出全部/当前 HTML | 分享网页 | 生成单文件网页，发给别人看 |

> 所有导入导出都带**进度条**；导入大文件请耐心等待，**不要中途关闭窗口**。
> 导入时软件会**自动跳过完全重复的内容**（同一内容重复导入不会产生两条）。

## 六、数据与备份（非常重要）

### 6.1 数据在哪？

**EXE 同目录 `data\`**：`prompts.db`（主库）、`backup\`（自动备份）、`images\`（图片）。

### 6.2 自动备份

每次启动软件都会自动把 `prompts.db` 复制一份到 `data\backup\`，**只保留最近 5 份**。若备份失败，底部状态栏会显示"● 备份失败：原因"（一般是磁盘满或文件夹被占用）。

### 6.3 手动备份 / 恢复

- **备份**：把整个 `data\` 文件夹复制到 U 盘/网盘；
- **恢复（推荐）**：启动软件 → "⇩ 导入" → "导入 JSON 备份"（需要先导出的 json）；
- **恢复（整体）**：关闭软件 → 用备份的 `prompts.db` 覆盖 `data\prompts.db` → 重新打开。

### 6.4 换电脑 / 换目录

- **方法一（最简单）**：把**整个 EXE 文件夹**（EXE + data）拷贝到新位置直接运行；
- **方法二（跨机）**：旧电脑导出 JSON → 新电脑导入 JSON。

> **常见误区**：源码运行版的数据在项目 `data\`，EXE 版的数据在 EXE 旁 `data\`，两者**互不相通**。想迁移请用 JSON 导出/导入，别直接复制数据库文件。

## 七、常见问题（FAQ）

| 问题 | 解决 |
| ---- | ---- |
| 双击没反应/闪退 | 右键"以管理员身份运行"；不要放在系统盘根目录或压缩包内 |
| "Windows 已保护你的电脑" | 点"更多信息 → 仍要运行" |
| 热键 Ctrl+Shift+P 无效 | 杀毒白名单或管理员运行（§2.3） |
| 状态栏提示"备份失败" | 磁盘空间不足或 `data\` 被占用，清理后重启 |
| 找不到"视觉风格分类" | 首次启动自动导入内置数据后出现；若还是找不到请确认 EXE 是完整版本 |
| 提示词只显示 1 行 | 请使用新版 EXE（V1.1 起默认 6 行可见，可展开） |
| 视频/图像下没内容 | 正常：内置数据已归入"视觉风格分类"；图像下已有 1151 条多来源数据 |
| 不小心删了条目 | 删除不可恢复；请养成定期导出 JSON 备份的习惯 |
| 想彻底重来 | 退出 → 删除 `data\` → 重启（自动重建内置数据） |
| 想导入网上找的 JSON 数据 | 点"⇩ 导入"→"导入 JSON 备份"，自动去重 |
| 数据会不会上传/联网 | **不会**。软件完全离线，数据只在本机 |
