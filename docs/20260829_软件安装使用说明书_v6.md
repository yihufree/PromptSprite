## 简介
PromptSprite（提示精灵）是一款本地运行的 AI 提示词管理工具。它提供**五级分类书架**（项目类别/根目录/一级分类/二级分类/条目）、**极速全文检索**、**一键复制**、**多格式导入导出**、**自动全量备份**与**每日增量备份**（支持换机合并），以及 **V1.5.0** 新增的**条目多位置（关联到/复制到/移动到）**、**就地新增**与**删除分类三级保护**。所有数据（提示词、分类、配图、备份）均存储在您电脑的 `data/` 目录中，**绝不联网**、**无任何隐私上传**。

内置内容：10 个根目录、约 **2555 条**提示词，按 4 个项目类别归类（精简模板，2026-09-07 起）。

## 安装指南
### 方式一：直接使用预编译 EXE（推荐）
1. 下载 `PromptSprite_v1.5.0.zip`（或 `.exe`）。
2. 解压到任意**英文路径**，如 `D:\PromptSprite\`。
3. 双击 `PromptSprite.exe` 运行。

### 方式二：从源码运行（开发者）
```powershell
pip install -r requirements.txt
python -m app.main
```

## 首次启动与初始化
- **自动建库**：首次运行自动创建 4 个项目类别、预置根目录并导入内置提示词（精简模板，约 2555 条），耗时约 5‑30 秒，请勿关闭窗口。
- **老数据迁移**：若检测到旧版本数据（根目录未归入项目类别），会自动弹出**数据迁移向导**：核对每个根目录归入的项目类别（默认已按映射预填），点击"执行迁移"即可；未匹配的默认归入"未明确分类"。取消可稍后在 **导入菜单 → 数据迁移向导…** 再次打开。
- **电脑代号**：增量备份用，首次退出时自动取本机主机名，可在设置中修改。

## 核心功能操作

### 6.1 项目类别与根目录
- **新增项目类别**：项目类别列顶部"➕ 新增项目类别"，或右键项目类别 → 新增。
- **重命名/删除项目类别**：右键 → 重命名/删除；删除前会提示其下根目录去向（默认归入"未明确分类"）。
- **新增根目录**：根目录列顶部"➕ 新增根目录"，输入名称后**选择所属项目类别**（未选择则归入"未明确分类"）。
- **移动根目录到其他项目类别**：右键根目录 → "移动到其他项目类别…"选择目标。

### 6.2 创建分类与条目
1. 选中项目类别 → 选中根目录 → "➕ 新增一级分类 / 新增二级分类"。
2. **就地新增（V1.5.0 推荐）**：在任一分级分类下，条目区顶部绿色"＋ 新增条目"即在该分类就地新增（该分类直接持有并显示"本级条目"，不要求必须是叶子分类）；"未分类"视图亦可新增。
3. **"✚ 快速新建"**：左侧四列导航（项目类别→根目录→一级→二级），**悬停**项目/根目录/分类即自动联动并锁定目标，光标自动进入名称框，连续录入。

### 6.3 编辑与删除
- **编辑**：选中条目 → 右侧详情区第一个字段 **"① 条目名称（风格名称）"** 与 ②~⑩ 字段 → "💾 保存"。
- **删除条目**：右键 → 删除 → 二次确认；若该条目同时存在于多个位置会先提示影响范围。
- **删除分类（V1.5.0 三级保护）**：有子分类需先处理下级；无子分类删除只解除其直挂条目在本分类的位置（无其它位置者转"未分类"，数据保留）；**级联删除整棵须手工输入确认短语**后再二次确认。

### 6.4 复制与移动
- 右键分类/根目录 → "复制到…/移动到…"；目标树按 项目类别→根目录→分类 组织；跨项目移动根目录＝调整归属，复制＝生成副本（重名自动加序号），源保留。
- **条目（V1.5.0）**：右键条目或使用详情区上方命令条（移动到…→关联到…→复制到…）——
  - **关联到…**：同一物理条目在多个分类显示，编辑一处各位置同步；
  - **复制到…**：为每个目标生成**独立副本**（含图片副本）；
  - **移动到…**：默认仅把当前位置搬到目标（其它关联保留），勾选"整体转移"则清空其它关联只保留新位置；在搜索/常用/未分类里操作时按整体转移处理。

### 6.5 搜索与筛选
- 顶部搜索框实时全文匹配；清空恢复当前视图；"📂 未分类"、"⭐ 常用"快速入口。

### 6.6 一键复制
- 选中条目 → "📋 复制全部 / 复制中文 / 复制英文"；⑩图像方案可点"打开"直达链接。
- **提示**：剪贴板内容对当前用户所有程序可见，请勿复制敏感信息。

### 6.7 导入与导出
| 格式 | 导入 | 导出 | 说明 |
|------|------|------|------|
| JSON | ✅ | ✅ | v2/v3 兼容；v3 含项目类别归属（增量备份用 v3） |
| Excel (.xlsx) | ✅ | ✅ | 表头含 领域/一级/二级/名称 等；**限制 ≤20MB**（流式读取） |
| Markdown | ✅ | ❌ | 内置手册导入 |
| HTML | ❌ | ✅ | 已转义，可浏览器打开分享 |

> 提示：Excel 导入的新根目录（表头"领域"中不存在的名称）将自动归入"未明确分类"，导入后可自行调整。

### 6.8 备份与恢复（全量 + 增量）
**全量备份（自动）**：每次启动自动保留最近 5 份 `data/backup/prompts_时间戳.db`；恢复＝关闭软件后用备份覆盖 `data/prompts.db`。

**增量备份（每日）**：每次关闭软件自动把"当日新增/修改"备份为
`data/backup/incremental/增量_{电脑代号}_{日期}.json`（当日再次新增后关闭会自动更新该文件）。
- **覆盖范围**：当日新增/修改的条目与分类（含"仅新建、还没有条目的空分类"）以及**当日删除**（删除清单），换机导入时能同步增、删、改与分类结构。
- 换机合并：导入菜单 → "导入增量备份…" → 选增量 JSON → 自动判重合并，并同步删除清单；
- 浏览导出：导出菜单 → "增量数据导出 Excel…/HTML…"；
- 文件携带：导出菜单 → "导出增量备份文件到…"（复制到 U 盘等）。

### 6.9 老版本数据迁移
- 旧版（根目录-一级-二级）数据升级后，根目录暂处"未分配"；
- 通过"数据迁移向导…"逐项核对映射并执行；未选择/未匹配自动归入"未明确分类"，**数据不会丢失**。

### 6.10 设置
1. 记住窗口大小；2. 默认视图（卡片/列表）；3. 详情字段显示（自动/全部/精简）；
4. **电脑代号**（增量备份区分多机）；5. **增量保留天数**（默认 30）；6. 关于。

### 6.11 条目多位置与就地新增（V1.5.0）
- **位置提示**：详情区顶部显示"📌 位置：主·…｜关联·…"，关联位置可点"×"逐处解除；同一条目编辑后各位置同步。
- **详情区名称字段**：详情/新增表单首字段为醒目大输入框 **"① 条目名称（风格名称）"**；详情区上方命令条统一为按钮（移动到… / 关联到… / 复制到… / 收藏 / 删除）。
- **新增入口**：条目区顶部绿色"＋ 新增条目"（字号 15 加粗）——在选中任一分级分类或"未分类"视图下即可就地新增。
- **精简模式**：详情区标题与"显示全部字段"按钮合并为一行，更紧凑。

## 常见问题与排查
| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| 启动闪退 / 无反应 | 杀毒拦截 / 路径含中文 | 加入白名单、改用纯英文路径 |
| 升级后根目录都在"未分配" | 尚未执行迁移 | 打开"数据迁移向导…"执行迁移 |
| 找不到增量备份文件 | 当日无新增不生成 | 新增/修改后正常退出即可 |
| 导入 Excel 卡死 | 文件过大（>20 MB） | 拆分文件或用 JSON 导入 |
| 全局热键无效 | 被占用 / 权限不足 | 以管理员身份运行一次 |
| 列中名称显示不全 | 列宽较窄（设计如此） | 悬停即可选中查看 |

## 卸载与清理
- 便携版：直接删除整个解压文件夹（含 `data/`）。
- 保留数据：先复制 `data/prompts.db` 与 `data/backup/` 到别处。
- 无残留：不写注册表、不装系统服务。
