## 1. 概览
本指南描述用 `build.py`（PyInstaller）将 PromptSprite 打包为单文件 EXE，并完成版本标签、自动化回归测试与 GitHub Releases 发布。V1.5.0 起新增**条目多位置（关联到 / 复制到（独立副本）/ 移动到）、条目就地新增与任意级本级条目、删除分类三级保护**（V1.4.0 已含四级分类体系、老数据迁移、每日增量备份）。打包前务必确保内置库为最新快照（含项目归属分配）。

> **注意**：所有路径建议使用全英文。

## 3. 代码准备
### 3.1 统一版本号
- `app/config.py`：`APP_VERSION = "1.5.0"`；
- `README.md` badge：`Version-1.5.0`、`Data-2555_prompts`；
- `关于`弹窗、说明书/需求规格等统一 `V1.5.0（2026-09-07）`；
- `build.py` 内注释的数据量（2555 条，精简模板）保持与真实库一致。

### 3.2 回归测试（打包前必做）
```bash
python -m app.database             # 数据库层（含 v2→v3 迁移）自测
python -m app.incremental_backup    # 增量备份模块自测
python -m app.gui_self_test        # 主界面 GUI 自动化回归（V1.5.0 起，需桌面环境）
python -m app.main --smoke          # GUI 冒烟（退出码 0）
```

### 3.3 更新内置素材库
```bash
python build.py --sync-db   # 将 data/prompts.db 复制为内置库（含四级归属）
```
同步前请确认 `data/prompts.db` 已通过"数据迁移向导"完成根目录归属分配，避免打包出"未分配"状态的库。

## 4. 打包流程
### 4.1 常规打包（单文件 EXE）
```bash
python build.py --onefile --output-dir dist\PromptSprite_v1.5.0
```
### 4.2 多文件打包
```bash
python build.py --onedir --output-dir dist\PromptSprite_v1.5.0_onedir
```
### 4.4 产物结构（示例）
```
dist\PromptSprite_v1.5.0\
│   PromptSprite.exe
│   README.md / LICENSE
│   resources\builtin_prompts.db      <-- 内嵌只读库（含四级归属）
│   data\
│       prompts.db
│       backup\prompts_*.db           <-- 全量备份（保留 5 份）
│       backup\incremental\增量_*.json <-- 每日增量备份
```
### 4.5 打包签名（可选）
用 `osslsigncode` 对 EXE 签名，规避 SmartScreen 拦截。


---

## 6. 自动化备份与恢复
- **全量备份**：`build.py` 打包前生成 `backup_config.yaml`（版本/时间戳/内置库哈希）。
- **增量备份**：运行期每次关闭自动生成 `data/backup/incremental/增量_{电脑代号}_{日期}.json`（保留 30 天，设置可调）。
- **恢复**：`data/prompts.db` 损坏时启动自动从内置库重建；增量 JSON 通过"导入增量备份…"合并。

## 8. 发布渠道与 GitHub Releases
| 渠道 | 说明 | 需注意 |
|------|------|--------|
| GitHub Releases | 在仓库 Release 页基于 `v1.5.0` 标签创建 | 上传 `dist\PromptSprite.exe`、`dist\PromptSprite_v1.5.0.zip`，附 SHA256 与变更说明 |

**Release 检查清单**：
1. 全部自测/冒烟通过；2. 内置库含最新四级归属；3. EXE 大小与 SHA256 记录；4. 变更说明（V1.5.0 条目多位置 / 就地新增 / 删除分类三级保护）；5. 源码 zip 附带 README/LICENSE/docs。

## 附录（脚本示例）
### 脚本 1：打包核心（build.py）
```python
from app import config
assert config.APP_VERSION == "1.5.0", "APP_VERSION 必须为 1.5.0"
# …onefile/onedir、--sync-db、smoke 回归与 v6 一致…
```

### 脚本 2：GitHub Actions CI（要点）
```yaml
on:
  push:
    tags: ['v*']
jobs:
  build:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.12" }
      - run: pip install -r requirements.txt pyinstaller
      - run: python build.py --onefile --output-dir dist
      - run: python -m app.main --smoke
      - uses: actions/upload-artifact@v4
        with:
          name: PromptSprite_v1.5.0.exe
          path: dist/*.exe
```
