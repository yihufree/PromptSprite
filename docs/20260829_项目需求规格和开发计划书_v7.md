# 20260829_项目需求规格和开发计划书_v7.md

## 项目背景
PromptSprite 是一款基于 Python3.12、CustomTkinter 6.0.0 与 SQLite 的本地 AI 提示词管理工具。当前发行版 **V1.5.0（2026-09-07）**，在 V1.4.0（五级分类书架、极速全文检索、一键复制、多格式导入导出、自动全量备份、每日增量备份、老数据迁移、热键托盘）基础上新增：**条目多位置（关联到 / 复制到（独立副本）/ 移动到）**、**条目就地新增与任一分级分类本级条目**、**删除分类三级保护**。定位：本地优先、无联网、数据私密的提示词管理平台。

## 1. 需求概述（精简模板基线：4 项目类别 / 10 根目录 / 2555 条；V1.5.0 新增条目多位置等）
| 功能模块 | 需求描述 | 优先级 | 实现状态 |
|----------|----------|--------|----------|
| 1. 分类体系 | 五级层级（项目类别 → 根目录 → 一级 → 二级 → 条目）；项目类别可增删改（精简模板内置 4 项）；根目录跨项目移动/复制；"未明确分类"兜底 | 高 | 已实现（V1.4.0） |
| 2. 老数据迁移 | 旧版（根目录-一级-二级）数据升级：映射表人工核对、未命中弹窗选择、未回答兜底"未明确分类"；自动弹出/菜单重开 | 高 | 已实现（V1.4.0） |
| 3. 检索 | 全文检索（全部文本字段、LIKE 通配符转义）、收藏、未分类、搜索框实时过滤 | 高 | 已实现 |
| 4. 复制 | 一键复制全部/中文/英文；⑩图像方案"打开"链接 | 高 | 已实现 |
| 5. 导入/导出 | JSON v2/v3 兼容（v3 含项目归属）；Excel 导入导出；Markdown 手册导入；HTML 导出（转义）；导入按内容判重 | 高 | 已实现（v3 于 V1.4.0） |
| 6. 全量备份 | 启动自动备份 prompts.db，保留最近 5 份 | 高 | 已实现 |
| 7. 增量备份 | 关闭时按日生成"当日变更"JSON v3（增量_{代号}_{日期}.json）、幂等重生成、保留 30 天（可设）、换机导入合并、导出 Excel/HTML 浏览；**支持"新增空分类"增量（categories 时间戳）与删除同步（deletion_log 删除清单）** | 高 | 已实现（V1.4.0 + 2026-08-29 增强） |
| 8. 热键/托盘 | Ctrl+Shift+P 唤起聚焦搜索；ESC 隐藏；托盘显示/退出 | 高 | 已实现 |
| 9. 可视化 | 卡片/列表切换；详情字段自动/全部/精简；全局锁定；状态栏层级统计 | 中 | 已实现 |
| 10. 设置 | 记住窗口大小、默认视图、详情策略、电脑代号、增量保留天数、关于弹窗 | 中 | 已实现（V1.4.0） |
| 11. 安全 | 本地存储、无联网、SQL 参数化、HTML 转义、无 eval/exec/pickle、路径越界校验、文件名安全过滤；Excel 导入 read_only + ≤20MB 限制 | 高 | 已实现（含 2026-08-29 审核后 P2 落实） |
| 12. 条目多位置 | **关联到**（同一条目在多个分类可见、编辑一处全同步）/ **复制到**（每目标独立副本，含图片新副本）/ **移动到**（可勾"整体转移"清空其它关联）；详情区"位置"提示行逐处解除 | 高 | 已实现（V1.5.0） |
| 13. 就地新增与任级直挂 | 条目区醒目绿色"＋新增条目"；任一分级分类都可持有并显示其"本级条目"（不再要求叶子） | 中 | 已实现（V1.5.0） |
| 14. 删除分类三级保护 | 有子分类先处理下级；无子分类删除仅解除直挂条目本位置（无其它位置转未分类）；级联整棵删除须手工输入确认短语 + 二次确认 | 高 | 已实现（V1.5.0） |

## 4. 风险与对策
| 风险 | 影响 | 对策 |
|------|------|------|
| 迁移中断致数据损坏 | 数据丢失 | 迁移前强制快照、单事务、schema_version 门控幂等、可回退 |
| 快照被自动备份清理 | 安全网丢失 | 快照改用 `snapshot_` 前缀（P2） |
| Excel 大文件内存风险 | 进程崩溃 | 导入前校验大小 + `read_only=True`（P2） |
| 增量与主库不一致 | 合并异常 | 每次退出幂等重生成、导入判重 |
| 剪贴板敏感信息泄露 | 隐私泄露 | UI 已标注可见性 |
