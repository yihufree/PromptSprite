# 🧩 PromptSprite（提示精灵）

> AI 提示词管理工具 —— 把杂乱无章的 Prompt 文档，变成 **五级分类书架 + 极速检索 + 一键复制 + 回收站（可恢复）+ 每日变更包 + 导入安全防护** 的本地神器。

![Version](https://img.shields.io/badge/Version-V1.8.0-blueviolet)
![Python](https://img.shields.io/badge/Python-3.12-green)
![UI](https://img.shields.io/badge/UI-CustomTkinter-2E8B57)
![License](https://img.shields.io/badge/License-MIT-yellow)
![Data](https://img.shields.io/badge/Data-100%25_本地存储-orange)

双击 `PromptSprite.exe` 即可使用。数据全部保存在本机 `data/` 目录，**无任何联网行为**。

- 源码：`git clone https://github.com/yihufree/PromptSprite.git`
- 仅供学习与个人使用（MIT License，见 [LICENSE](LICENSE)）。

## 🆕 版本记录

### V1.8.0（2026-09-10）

> 本轮**只改界面与交互，不改数据格式、不改库结构**——直接覆盖升级即可，数据完全兼容。

- **工具栏重排与瘦身**：按钮顺序固定为 🔒锁定 → 🗂目录隐藏/目录显示 → 📂无类条目 → ⭐常用 → ✚新建 → ⇩导入 → ⇧导出 → ⚙设置 → 搜索框；搜索框移到最右端（最小 10 个汉字宽、随窗口变宽），各按钮宽度收紧贴合文字；
- **"项目列"→"目录隐藏 / 目录显示"（功能升级）**：由只能收起"项目类别"一列，改为可**任选隐藏 项目类别/根目录/一级/二级（连续前缀）**；对话框右侧新增"快捷选项：全部隐藏 / 全部显示"；底部常驻栏新增 **🗂** 小图标可一键全隐/全显；
- **窗口最小宽度动态化**：四列全显示时 ≈1420；隐藏得越多可缩得越窄（四列全隐藏 ≈1028，只剩"条目 + 详情"两栏）；
- **搜索输入防抖**：解决"刚敲一个字就整库刷新、输入长句卡顿"的问题——停止输入约 1.5 秒后才查询；新增搜索框右侧 **🔍** 图标点击即搜，回车仍可立即搜索；
- **新增"✏️ 编辑 / 👁 浏览"切换**：浏览态详情只读（仍可选中 Ctrl+C），保存/重置/删除/移动/关联/复制等编辑类按钮置灰，杜绝误改；
- **详情区命令条调整**："移动到/关联到/复制到"去掉名称末尾省略号并靠左紧挨"编辑/浏览"（编辑/浏览移至最右），"☆ 收藏"移至最左；保存/重置/复制全部/中文/英文宽度按"完整显示文字"标定，任何窗口宽度下都不裁切；
- **条目列悬停"条目名称一览"修补**：浮层不再"鼠标一移开就消失"，可把鼠标移进浮层滚动；在条目区滚动滚轮时浮层同步滚动；
- **底部常驻栏重排**：靠右停靠（🕒 新增历史 ｜ ♻ 删除历史/回收站 ｜ 🗑 删除当前条目），最左留出 🗂 一键显隐图标；按钮宽度贴合文字；
- **详情区 ②~⑦ 折叠形态统一**：整组默认折叠为 1 行标题（不再占空白），点"展开"/"⏵ 显示全部字段"全部展开；
- **按钮更名**："未分类"→"无类条目"、"快速新建"→"新建"（仅名称，功能不变）。

### V1.7.0（2026-09-09）

- **"增量备份"更名"每日变更包"＋计数命名**：导出文件改为 `变更包_{电脑代号}_{日期}_add_{新增/修改合计}_del_{删除条目数}.json`（如 `变更包_DESKTOP-053MORJ_2026-09-08_add_0_del_1380.json`，一眼识别"负增量/纯删除包"）；当日幂等仅一份，兼容清理旧"增量_"前缀遗留文件；导出到外部前先弹摘要，纯删除包红字警告"⚠ 负增量，谨慎分发"；
- **JSON v4 变更包格式**：导出含 `type`（full/change）与 `summary` 计数元信息；导入兼容 v2 / v3 / v4 老文件；
- **变更包导入安全向导（二维选择）**：先预览来源与增删计数，再二维选择（①是否合并新增/修改 ②删除清单：忽略删除 / 正常应用删除 / ⑤逆向恢复）；正常应用删除须输入确认短语"确认删除"、逆向恢复须输入"恢复删除"；目标库同步时间落后于包日期时红色提示并建议"忽略删除"；
- **同步删除安全化**：删除清单重放一律"先入回收站"（完整快照 + 保留图片），物理释放只发生在"彻底删除/清空回收站"；分类删除复用安全级联路径；
- **导入前自动快照**：`prompts_preimport_时间戳.db`（独立前缀、不参与自动清理、失败中止导入），误操作可一键回滚；
- **自动全量备份策略升级**：按天去重（同日只留最后一份）＋默认保留 **30 份**（可在设置修改）＋只清理标准命名 `prompts_YYYY-MM-DD_*.db`，手动快照（`snapshot_*`、`*_施工前_*` 等）永不清理；
- **新增"数据比对…"**：与任一备份 `*.db` 只读比对（差异概览 + 明细 + 导出 HTML 报告），用于核对当前库与历史备份的差异；
- **携带被删快照（默认关）＋⑤ 逆向恢复**：删除日志留存完整 payload 快照；开启"携带被删快照"后，变更包删除项带完整快照，可在向导中"逆向恢复"，把删除数据反向加回（无快照的包按钮置灰）；
- **根因复盘（导入误删事故）**：旧版把"每日变更包"称为"增量备份"，且导入即重放删除、删除不可逆——实测导入某"纯删除（负增量）包"后条目由 3987 降至 2555 且严重卡顿。本版以"导出披露 + 导入预览 + 范围选择 + 自动快照 + 回收站可逆 + 性能修复"六重措施根治（详见 [开发工作记录 09](20260908_PromptSprite_09_开发工作记录.md) 第 4~10 轮）。

## 📊 内置数据（内置精简模板）

- 打包版内嵌**打包时的最新完整库**（`app/resources/builtin_prompts.db`），首次运行若无 `data/prompts.db` 自动复制建库（已有数据绝不覆盖）；源码开发版首次启动自动导入"内置手册"（归入"视觉风格分类"）。

## 🚀 快速开始

### 方式一：直接使用（普通用户）

1. 从 [GitHub Releases](https://github.com/yihufree/PromptSprite/releases) 下载 `PromptSprite_<日期YYMMDD>_V<版本号>.exe`（如 `PromptSprite_260910_V1.8.0.exe`）；
2. 双击运行（首次自动建库并导入内置数据；可放在任意目录，数据保存在 EXE 同目录 `data/` 下）；
3. 详细图文说明见 [《软件安装使用说明书 V8》](docs/20260910_软件安装使用说明书_v8.md)。

### 方式二：源码运行（开发者）

```powershell
# 1. 克隆仓库
git clone https://github.com/yihufree/PromptSprite.git
cd PromptSprite

# 2. 创建虚拟环境并安装依赖（Python 3.12，兼容 3.10+）
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 3. 启动（以下三种方式等价）
python app/main.py        # 直接运行主文件（推荐）
python run.py             # 根目录启动器
python -m app.main --smoke    # 冒烟测试：5 秒后自动退出
```

运行依赖：`customtkinter` / `Pillow` / `pyperclip` / `openpyxl` / `keyboard` / `pystray`（见 [requirements.txt](requirements.txt)，直接运行主文件缺依赖时会自动安装）。

### 📦 打包发布

```powershell
python build.py           # 一键打包（自动装依赖/生成图标/内嵌最新完整库/PyInstaller 单 EXE/校验）
```

产物自动按 **`PromptSprite_<日期YYMMDD>_V<版本号>.exe`** 命名（如 `dist\PromptSprite_260910_V1.8.0.exe`，单文件、无控制台窗口）。详见 [《打包发布指南 V8》](docs/20260909_打包发布指南_v8.md)。

## 🗄️ 数据与隐私

- **100% 本地**：单文件 SQLite 数据库 `data/prompts.db`；打包态为 EXE 同目录 `data/`，开发态为项目根 `data/`。软件不联网、不上传、不收集任何数据。
- **图片与备份**：条目关联图片存 `data/images/`；自动全量备份与导入前快照存 `data/backup/`；每日变更包存 `data/backup/incremental/`。
- **数据模型**：项目类别/根目录/一级/二级/条目五级；分类为全局共享树，删除根目录仅解除关联；`trash` 表保存被删完整快照（可恢复）；旧库启动自动迁移（v1→v2→v3），`deletion_log` 老库自动补 `payload` 列（V1.7.0）。
- **隐私提醒**：变更包可能包含条目内容与删除清单；"携带被删快照"默认关闭，分发/导入前请先查看摘要确认（纯删除包会有红字警告）。

## ⚠ 已知限制与说明（2026-09-10，V1.8.0 复核补充）

1. **搜索的 1.5 秒延迟是刻意设计**：V1.8.0 起输入过程不实时查询（避免整库刷新卡顿），停止输入约 1.5 秒后才搜索；要"立刻出结果"请点搜索框右侧 **🔍** 或按回车。
2. **窗口最小宽度会随目录显隐变化**：四列全显示时约 1420、四列全隐藏时约 1028（该下限由顶部工具栏"完整显示所需宽度"决定，低于它"导入/导出/设置/搜索"会被挤出可视区）。若把窗口从"目录全隐藏"的窄宽度直接恢复显示四列，窗口会被最小宽度自动顶宽。
3. **多位置条目的 JSON/Excel 导出往返**：同一分类子树导出时，多位置（主挂靠 + 关联）条目会在文件里出现多行，再次导入会变成多份独立副本而非原"关联关系"（B-13 记录；如需保真请用整库 JSON 或保留多位置功能原地使用）。
4. **数据比对口径**：条目差异按"详情内容键（content_key）"识别；同名不同内容会被视为不同条目，内容一致但位置不同的两条视为同一条（已按分类 id 修复同名分类互相覆盖问题）。
5. **"修改"的换机同步语义**：当前以内容判重合并，"修改"表现为"新增一条 + 原条保留"；真正的"更新/编辑同步"需引入稳定条目 ID（后续增强）。
